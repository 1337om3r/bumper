❓ BUMPER USER GUIDE & INSTRUCTIONS

1. How to get your Discord Token?

Open Discord in Browser -> Press F12 -> Go to Console or Network tab -> Search for authorization headers -> Copy your user token.

2. How to find your Target Channel ID?

Enable Developer Mode in Discord Settings -> Right-click the channel where Disboard /bump command is executed -> Click Copy Channel ID.

3. Safe & Automated Bumping

BUMPER handles rate-limits automatically and triggers /bump commands according to Disboard's 2-hour cooldown policy.
